# Murali — portfolio

A one-page portfolio for Murali, a Full Stack Developer. Built with React and Vite.

Arogya Adarsh, DottFit, and Ananthsai Caterers are live websites.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

Live site (GitHub Pages): https://murali8943.github.io/murali-portfolio/

## Before you share it

Edit `src/data/site.js`:

- `email` — your real email address
- `whatsappNumber` — your number in international form, digits only, such as `9198XXXXXXX`
- `social` — your GitHub and LinkedIn profile URLs

The contact buttons use the email, WhatsApp number, GitHub, and LinkedIn already set in that file.
